# v1.0.0 (1.19-1.20)

### 更新内容
将 `1.21` 的汉化内容同步至 `1.21-` 版本中，以支持非 `Sakura` 魔改的 `Masa Mods` 汉化

目前仅验证了 `1.19.x` 和 `1.20-1.20.4` 版本的汉化，其它版本并不能保证适配

### 修复错误
无
### 吐槽
听到社区有 `1.21-` 版本汉化的需求，便做了这一版，除非有重大错误，不然不会再继续与 `1.21` 版本汉化同步了，算是绝唱吧

Enjoy XDD
